# Инженерный калькулятор

Инженерный калькулятор с поддержкой арифметических операций, тригонометрических функций, численного интегрирования, операций с матрицами и построения графиков. Все вычисления сохраняются в истории.

## Установка и запуск

Для работы программы необходимо установить зависимости:
pip install matplotlib numpy

Запуск программы:
python calculator.py

В коде:
calc = EngineeringCalc('deg')  # 'deg' - градусы, 'rad' - радианы
calc.run()

## Меню программы

1. Арифметика
2. Тригонометрия
3. Интегрирование
4. Матрицы
5. Построение графиков
6. Показать историю
7. Очистить историю
8. Переключить режим тригонометрии
9. Выход

## Классы и методы

History — управление историей вычислений
add(category, operation, result) — добавить запись в историю
show() — отобразить историю
clear() — очистить историю

BasedCalculator — арифметические операции
add(a, b) — сложение, возвращает a + b
minus(a, b) — вычитание, возвращает a - b
mul(a, b) — умножение, возвращает a * b
div(a, b) — деление, возвращает a / b
pow(a, b) — возведение в степень, возвращает a ** b
root(a, b) — извлечение корня b-й степени из a, возвращает a ** (1/b)

TrigCalculator — тригонометрические функции
sin(a) — синус угла a
cos(a) — косинус угла a
tan(a) — тангенс угла a
asin(a) — арксинус a (значение от -1 до 1)
acos(a) — арккосинус a (значение от -1 до 1)
atan(a) — арктангенс a
set_mode(mode) — переключение режима, mode может быть 'deg' (градусы) или 'rad' (радианы)

IntegrationCalculator — численное интегрирование методом трапеций
integrate(name, a, b, n=1000) — вычисляет определенный интеграл функции name от a до b с шагом n
add_function(name, func) — добавляет пользовательскую функцию

Встроенные функции для интегрирования:
square — x в квадрате
sine — синус x
cosine — косинус x
linear — 3x + 1
cubic — x в кубе
exp — экспонента e в степени x

MatrixCalculator — операции с матрицами
add_matrices(A, B) — сложение двух матриц
subtract_matrices(A, B) — вычитание матриц
multiply_matrices(A, B) — умножение матриц
multiply_by_scalar(M, scalar) — умножение матрицы на скаляр
transpose(M) — транспонирование матрицы
determinant(M) — вычисление определителя матрицы
inverse(M) — вычисление обратной матрицы

GraphCalculator — построение графиков
plot(*functions) — построение графиков переданных функций

EngineeringCalc — главный класс калькулятора
run() — запуск интерактивного режима
show_menu() — отображение главного меню
